================================================================
 OSCB FORMAT — TECHNICAL DOCUMENTATION
================================================================

----------------------------------------------------------------
 0. PURPOSE AND CONVENTIONS
----------------------------------------------------------------

OSCB (Oscillator Bitstream) is a compact bit-level format for
describing a musical sequence for a web player.
A bit stream packed into bytes MSB-first (bit 7 of the byte
is read first).

+----------------+----------------------------------------------+
| Property       | Value                                        |
+----------------+----------------------------------------------+
| Magic          | 4F 53 43 42 ("OSCB")                         |
| Bit order      | MSB-first                                    |
| Byte order     | big-endian for multi-bit fields              |
| Padding        | last byte is zero-padded to the boundary     |
| End of stream  | reading past the end returns bit 0           |
+----------------+----------------------------------------------+

Read primitives:
  I(n) — unsigned integer of n bits (MSB-first)
  G()  — unsigned integer in Elias gamma code of value+1

----------------------------------------------------------------
 1. COMPRESSED STRUCTURE (BITSTREAM)
----------------------------------------------------------------

+--------------+--------+-----------------------------------------+
| Field        | Bits   | Description                             |
+--------------+--------+-----------------------------------------+
| magic        | 32     | ASCII "OSCB" (4F 53 43 42)              |
| version      | 8      | version; ignored by decoder; rec. 1     |
| tick         | 8      | tick duration, ms (1..255)              |
| duration     | 32     | full track duration, ticks              |
| ac           | 16     | number of instruments (>=1)             |
| instruments  | var.   | ac instrument blocks (see below)        |
| ec           | 32     | number of events                        |
| events       | var.   | ec event blocks (see below)             |
+--------------+--------+-----------------------------------------+

Instrument (note preset), ac entries in a row:

+--------+--------+-------------------------------------------+
| Field  | Bits   | Description                               |
+--------+--------+-------------------------------------------+
| wave   | 2      | 0=sine 1=saw 2=noise 3=square             |
| note   | 7      | MIDI note 0..127                          |
| vol    | 4      | volume 0..15; amplitude=(vol+1)/16        |
| dur    | G()    | note duration, ticks                      |
+--------+--------+-------------------------------------------+

Event, ec entries in a row:

+--------+--------+-------------------------------------------+
| Field  | Bits   | Description                               |
+--------+--------+-------------------------------------------+
| instr  | ib     | instrument index; ib=max(1,bitlen(ac-1))  |
| delta  | G()    | time increment from prev. event, ticks    |
+--------+--------+-------------------------------------------+

Event time = cumulative sum of delta * tick/1000 (sec).
Events go strictly in non-decreasing time order (delta>=0).
An event inherits all sound parameters from its instrument.

Index width ib (examples):
  ac=1..2 -> ib=1 | ac=3..4 -> ib=2 | ac=5..8 -> ib=3 | ac=9..16 -> ib=4

G() integer encoding (Elias gamma of v+1):
  v=0 -> 1        v=3 -> 00100   v=6 -> 00111
  v=1 -> 010      v=4 -> 00101   v=7 -> 0001000
  v=2 -> 011      v=5 -> 00110
The decoder limits leading zeros to 31: delta limit ~ 2^31.

Derived quantities:
  t   = tick/1000                 seconds per tick
  f   = 440 * 2^((note-69)/12)    Hz
  amp = (vol+1)/16                0.0625..1.0

Minimal file example (sine A4=69, vol=15, dur=4 ticks,
tick=100 ms, 2 events with delta 0 and 4):

  4F 53 43 42            "OSCB"
  01                     version
  64                     tick = 100 ms
  00 00 00 08            duration = 8 ticks
  00 01                  ac = 1
  00 1000101 1111 00101  instrument: wave=0 note=69 vol=15 dur=G(4)
  00 00 00 02            ec = 2
  0 1                    event 0: instr=0 delta=G(0)
  0 00101                event 1: instr=0 delta=G(4)
  00...                  padding to byte boundary

----------------------------------------------------------------
 2. JSON STRUCTURE
----------------------------------------------------------------

Top level:

+-------------+--------+------------------------------------------+
| Field       | Type   | Meaning                                  |
+-------------+--------+------------------------------------------+
| version     | string | format marker; editor uses "osc-edited"  |
| duration    | number | track length, sec; must be >= max(t+d)   |
| bpm         | number | tempo for grid/snap; not used in synth   |
| oscillators | array  | list of tracks (oscillator groups)       |
+-------------+--------+------------------------------------------+

Track (oscillators[i]):

+--------+--------+----------------------------------------------+
| wave   | string | waveform: "sine"|"saw"|"square"|"noise"    |
| events | array  | track notes; order not guaranteed          |
+--------+--------+----------------------------------------------+

Event (events[j]):

+----+--------+-------------------------------------------------+
| t  | number | note start, sec; >=0                            |
| f  | number | frequency, Hz; for "noise" — tint/ignored       |
| a  | number | amplitude 0..1 (quantized to 1/16 in OSCB)      |
| d  | number | duration, sec; >0                               |
+----+--------+-------------------------------------------------+

Semantics and relations:
 - All events of one track share the waveform `wave`.
 - `f` is converted to MIDI (7 bits) in OSCB: f=440*2^((m-69)/12).
   Fractional/off-target frequencies are rounded and lose precision.
 - `a` and `d` live IN THE INSTRUMENT in OSCB, therefore events
   with different a/d for the same note become different instruments.
 - `bpm` and `duration` are editor metadata; synthesis uses
   only t/f/a/d.

Example:

{
  "version": "osc-edited",
  "duration": 32.5,
  "bpm": 128,
  "oscillators": [
    {"wave":"saw",
     "events":[{"t":0.0,"f":220.0,"a":0.8,"d":0.25},
               {"t":0.25,"f":246.94,"a":0.7,"d":0.25}]},
    {"wave":"noise",
     "events":[{"t":0.0,"f":2000.0,"a":0.9,"d":0.1}]}
  ]
}

----------------------------------------------------------------
 3. json2oscb CONVERTER
----------------------------------------------------------------

Algorithm:
 1. Choose tick_ms as an integer 1..255 (e.g. 10, or from BPM grid).
 2. Each event: note=round(69+12*log2(f/440))&127;
    vol=clamp(round(a*16)-1,0,15); dur=max(1,round(d/tick_sec)).
    Discard events with a<=0 (zero volume is not representable).
 3. Group into instruments by the unique key
    (wave,note,vol,dur); index = order of first appearance.
 4. Sort all events by t; delta=round((t-t_prev)/tick_sec),
    cumulative, non-negative.
 5. duration_ticks = max(duration field, end of the last note).
 6. Pack bits MSB-first, pad to a byte boundary.

Wave map: sine=0, saw=1, noise=2, square=3.

Reference implementation (Python):

import json, math, gzip

WAVE = {"sine":0, "saw":1, "noise":2, "square":3}

class BW:
    def __init__(self): self.b=[]
    def u(self,v,n):
        for i in range(n-1,-1,-1): self.b.append((v>>i)&1)
    def g(self,v):
        v+=1; n=v.bit_length()
        self.b+=[0]*(n-1); self.u(v,n)
    def out(self):
        self.b+=[0]*((-len(self.b))%8)
        return bytes(sum(bit<<(7-i) for i,bit in
                   enumerate(self.b[k:k+8]))
                   for k in range(0,len(self.b),8))

def f2m(f):
    return 0 if f<=0 else int(round(69+12*math.log2(f/440.0)))

def json2oscb(data, tick_ms=10):
    t=tick_ms/1000.0
    instr={}; ilist=[]; evs=[]
    flat=[]
    for osc in data.get("oscillators",[]):
        w=WAVE.get(osc.get("wave","sine"),0)
        for e in osc.get("events",[]):
            if float(e["a"])<=0: continue
            flat.append((float(e["t"]),w,e))
    flat.sort(key=lambda x:x[0])
    prev=0; last_end=0
    for ts,w,e in flat:
        note=f2m(float(e["f"]))&127
        vol=max(0,min(15,round(float(e["a"])*16)-1))
        dur=max(1,round(float(e["d"])/t))
        key=(w,note,vol,dur)
        if key not in instr:
            instr[key]=len(ilist); ilist.append(key)
        cur=round(ts/t)
        evs.append((instr[key],max(0,cur-prev)))
        prev=cur
        last_end=max(last_end,cur+dur)
    dur_t=max(last_end,round(float(data.get("duration",0))/t),1)

    b=BW()
    for c in b"OSCB": b.u(c,8)
    b.u(1,8); b.u(tick_ms,8); b.u(dur_t,32); b.u(len(ilist),16)
    for w,note,vol,dur in ilist:
        b.u(w,2); b.u(note,7); b.u(vol,4); b.g(dur)
    b.u(len(evs),32)
    ib=max(1,(len(ilist)-1).bit_length())
    for idx,delta in evs:
        b.u(idx,ib); b.g(delta)
    return b.out()
